# Cuentos y mates

Web para aprender matemáticas a través de cuentos, libros y álbumes ilustrados en Educación Infantil y Primaria (LOMLOE · Decreto 38/2022 de Castilla y León).

- Filtra los cuentos por **curso** y **sentido matemático**.
- Cada cuento ofrece ideas para trabajar mates y desplegables con los **40 tipos de tareas** y los **8 talleres creativos**.
- Cada ficha se puede descargar en **PDF**, igual que la **guía de aula**.
- El curso y la edad son relativos: cada cuento puede usarse en varios cursos, sentidos y competencias según la justificación pedagógica.

**Autoría:** Mercedes Carpintero Gómez.
